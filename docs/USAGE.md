# 사용법 매뉴얼

DaramVncServer(`daramvnc.exe`)를 실행하고, 인증을 설정하고, 서비스로 설치하고, 뷰어로 접속하는 방법입니다. 소스에서 빌드하는 방법은 [빌드 매뉴얼](BUILD.md)을 보세요.

> **먼저 읽어 주세요 — 검증 범위**
> 서비스 설치, 잠금 화면·UAC 화면 캡처, 멀티 모니터, 클립보드 공유, 실제 해상도 전환, 그리고 **TigerVNC·RealVNC·UltraVNC 같은 실제 뷰어와의 호환성은 이 개발 환경에서 직접 확인하지 못했습니다.** 이 항목들은 구현되어 있지만, 처음 도입할 때 시험 환경에서 먼저 확인하세요. 확인된 범위는 README의 "검증 현황"에 있습니다.

## 1. 빠른 시작

```bat
daramvnc.exe passwd me     :: 로그인 사용자와 비밀번호 설정 (처음 한 번)
daramvnc.exe run           :: 0.0.0.0:5900 에서 대기
```

- 서버는 기본으로 **모든 IPv4 인터페이스(0.0.0.0)의 5900 포트**에서 접속을 받습니다. 다른 PC의 뷰어로 `이_PC_주소:5900`에 접속하세요.
- **인증 정보가 없으면 서버가 시작을 거부합니다.** 인증 없이 모든 인터페이스에 열리는 일을 막기 위한 것이므로, 먼저 `passwd`를 실행하세요.
- `Enter`를 누르면 종료합니다.
- 인증 없이 이 PC 안에서만 시험해 보려면 `daramvnc.exe run --bind 127.0.0.1`로 실행합니다. 이 모드에서는 로그인 없이 접속되므로 같은 PC의 다른 사용자 계정도 접속할 수 있습니다.

## 2. 원격 접속 설정

### 2.1 로그인 사용자 만들기

```bat
daramvnc.exe passwd me
```

비밀번호를 두 번 입력합니다(8자 이상, 입력은 화면에 표시되지 않음). 비밀번호 자체는 저장하지 않고 **PBKDF2-SHA256 해시**만 `daramvnc.conf`의 `user=`, `password_hash=`에 기록합니다. 같은 명령을 다시 실행하면 비밀번호가 바뀝니다.

### 2.2 수신 주소 지정

`daramvnc.conf`에 `bind=`를 쓰거나 실행할 때 `--bind`를 줍니다.

| `bind` 값 | 동작 |
|---|---|
| `0.0.0.0` (기본) | 모든 IPv4 인터페이스 |
| `127.0.0.1` | 이 PC에서만 접속 (인증 없이 시험할 때) |
| `::` | IPv4와 IPv6 모두 (듀얼스택) |
| `::1` | IPv6 루프백만 |
| 특정 IP | 그 인터페이스만 (예: 사내망 주소) |

```bat
daramvnc.exe run --bind ::           :: IPv4와 IPv6 모두
daramvnc.exe run --bind 192.168.0.10 :: 한 인터페이스만
```

- **인증 정보가 없으면 루프백(`127.0.0.1`, `::1`)이 아닌 주소에서는 서버가 시작을 거부합니다.** 기본값 `0.0.0.0`도 여기에 해당하므로 먼저 `passwd`를 설정하세요.
- 잘못된 주소는 시작할 때 `invalid bind address`로 알려 줍니다.

### 2.3 TLS 인증서

첫 실행 때 자체 서명 인증서를 실행 파일 폴더에 만듭니다 (`server.crt`, `server.key`, P-256 키, 유효기간 10년). 직접 발급한 인증서를 쓰려면 PEM 파일 경로를 `cert=`, `key=`에 지정하세요.

자체 서명 인증서라서 뷰어가 처음 접속할 때 인증서 경고를 띄웁니다. 지문(fingerprint)이 맞는지 확인하고 수락하세요. 신뢰할 수 있는 인증서를 쓰면 경고가 없어집니다.

### 2.4 선택: VNC 비밀번호 (레거시 호환)

```bat
daramvnc.exe vncpasswd
```

사용자 이름 없이 비밀번호만 쓰는 뷰어를 위한 것으로, **DPAPI(컴퓨터 범위)로 보호해** `vnc_password_dpapi=`에 저장합니다.

- TLS 위의 X509Vnc 방식으로 쓰는 것이 기본입니다.
- TLS 없는 옛 VNC 인증(DES 챌린지)은 약하므로 **기본으로 꺼져 있고**, `allow_legacy_vnc_auth=1`을 지정해야 제공합니다. 이 방식은 비밀번호 앞 8자만 사용합니다.
- DPAPI로 보호한 값은 이 컴퓨터에서만 복호화됩니다. 설정 파일을 다른 PC로 옮기면 `vncpasswd`를 다시 실행해야 합니다.

### 2.5 로그인 실패 제한

접속 주소별로 로그인에 실패할 때마다 응답이 늦어지고, **6번 실패하면 그 주소는 마지막 실패로부터 5분간 차단**됩니다. 성공하면 기록이 지워집니다.

## 3. 설정 창 (GUI)

```bat
daramvnc.exe gui
```

서비스를 제어하고 `daramvnc.conf`를 편집하는 창입니다. 관리자 권한이 필요해서 실행하면 UAC 확인 창이 뜨고, 허용하면 권한이 상승된 창이 열립니다. 허용하지 않으면 창이 열리지 않습니다.

| 영역 | 기능 |
|---|---|
| 서비스 | 상태 표시(2초마다 갱신), 설치·제거·시작·중지·재시작, 방화벽 규칙 만들기/삭제. 설치할 때 방화벽 규칙을 함께 만들지 선택할 수 있습니다 |
| 접속 | 수신 주소(목록에서 고르거나 직접 입력), 포트, 보기 전용, H.264, TLS 없는 옛 VNC 인증 |
| 화질 | JPEG 품질 상한·하한 |
| 계정 | 로그인 사용자 이름과 비밀번호, VNC 비밀번호 (`passwd`, `vncpasswd`와 같은 방식으로 저장) |
| 로그 | 로그 파일 경로, 회전 크기, 보관 수, 메모장으로 로그 열기 |

- **저장**은 설정 파일의 해당 키만 갱신하고 사용자·비밀번호 해시·인증서 경로·주석은 그대로 둡니다. 잘못된 값(범위를 벗어난 포트, 형식이 틀린 주소, 하한이 상한보다 큰 JPEG 품질, 숫자가 아닌 값)은 저장 전에 알려 주고 파일을 바꾸지 않습니다. 인증 정보가 없는 상태에서 `127.0.0.1`/`::1`이 아닌 주소를 저장하는 것도 막습니다.
- 서버는 설정을 시작할 때만 읽으므로, 서비스가 실행 중이면 **저장 후 서비스 재시작**을 누르거나 재시작해야 적용됩니다. 재시작하면 접속 중인 뷰어는 끊어집니다.
- 비밀번호 설정은 저장 버튼과 별개로 그 즉시 설정 파일에 기록됩니다.
- 이 창은 포그라운드로 실행 중인 서버(`daramvnc run`)는 제어하지 않습니다. 서비스로 설치한 서버를 대상으로 합니다.
- 실행 중인 서버의 접속자 목록이나 설정 즉시 적용은 아직 없습니다.

## 4. 서비스로 설치 (자동 시작)

**관리자 권한** 명령 프롬프트에서:

```bat
daramvnc.exe passwd me
daramvnc.exe install --open-firewall
daramvnc.exe start
```

| 명령 | 동작 |
|---|---|
| `install` | `DaramVncServer` 서비스를 등록합니다(부팅 시 자동 시작). 서비스 표시 이름은 "Daram VNC Server" |
| `install --open-firewall` | 설정의 포트로 들어오는 TCP를 허용하는 방화벽 규칙(`DaramVncServer`)도 만듭니다 |
| `start` / `stop` | 서비스 시작 / 중지 |
| `uninstall` | 서비스를 제거하고 방화벽 규칙을 지웁니다 |

- 권한이 없으면 `... failed (Win32 error 5) - run as Administrator`가 나옵니다.
- **설치하기 전에 `daramvnc.exe`를 최종 위치에 두세요.** 서비스는 등록 당시의 실행 파일 경로를 가리키고, 설정·인증서·로그도 그 폴더를 씁니다.
- 서비스는 활성 콘솔 세션에 **SYSTEM 권한 에이전트**를 띄워 로그인 화면과 UAC 화면(보안 데스크톱)을 따라가도록 설계되어 있습니다. (위 검증 범위 안내 참고)
- 설정 파일(`daramvnc.conf`)을 바꾸면 서비스를 `stop` 후 `start`로 다시 시작해야 적용됩니다.

## 5. 뷰어로 접속

주소는 `호스트:포트` (기본 포트 5900)입니다. 예: `192.168.0.10:5900`.

- **TLS + 사용자/비밀번호(VeNCrypt X509Plain)** 를 지원하는 뷰어에서 인증 방식을 선택하고 `daramvnc passwd`로 만든 사용자 이름과 비밀번호를 입력합니다. TigerVNC 같은 뷰어가 이 방식을 지원합니다.
- 접속 계정 없이 비밀번호만 쓰려면 `vncpasswd`를 설정하고 X509Vnc를 지원하는 뷰어를 쓰세요.
- 성능을 위해 뷰어에서 **Tight 또는 ZRLE 인코딩과 자동(Auto) 품질**을 쓰는 것이 좋습니다. 서버는 지연을 재서 JPEG 품질을 스스로 조절합니다. 뷰어에서 품질을 낮게 지정하면 그 값이 상한이 됩니다.
- ContinuousUpdates, Fence, Cursor, ExtendedDesktopSize, Extended Clipboard를 지원하는 뷰어일수록 반응성이 좋습니다.

## 6. 설정 파일 (`daramvnc.conf`)

실행 파일과 같은 폴더에 있는 `키=값` 텍스트 파일입니다. `#`이나 `;`로 시작하는 줄은 주석이고, 모르는 키는 무시합니다. 파일이 없으면 기본값을 씁니다. `passwd`/`vncpasswd`는 해당 키만 갱신하고 나머지는 보존합니다. `--config FILE`로 다른 파일을 쓸 수 있습니다.

| 키 | 기본값 | 설명 |
|---|---|---|
| `bind` | `0.0.0.0` | 수신 주소 (2.2 참고) |
| `port` | `5900` | TCP 포트 |
| `user` | (없음) | 로그인 사용자 이름 (`passwd`가 기록) |
| `password_hash` | (없음) | PBKDF2-SHA256 해시 (`passwd`가 기록, 직접 편집하지 마세요) |
| `vnc_password_dpapi` | (없음) | DPAPI로 보호한 VNC 비밀번호 (`vncpasswd`가 기록) |
| `allow_legacy_vnc_auth` | `0` | TLS 없는 옛 VNC 인증 허용 |
| `view_only` | `0` | `1`이면 키보드·마우스·클립보드 입력을 모두 무시 (화면 보기 전용) |
| `jpeg_quality_max` | `85` | JPEG 품질 상한 (1~99) |
| `jpeg_quality_min` | `40` | JPEG 품질 하한 (1~99, 상한보다 크면 상한에 맞춤) |
| `h264` | `0` | H.264 사용 (아래 7장) |
| `cert`, `key` | 실행 폴더의 `server.crt`, `server.key` | TLS 인증서와 키(PEM). 없으면 첫 실행 때 생성 |
| `log` | 실행 폴더의 `daramvnc.log` (서비스) | 로그 파일 경로 |
| `log_max_mb` | `5` | 로그 파일이 이 크기(MB)에 이르면 회전. `0`이면 회전 안 함 |
| `log_keep` | `3` | 보관할 이전 로그 파일 수 (`.1`, `.2`, `.3`). `0`이면 남기지 않음 |

불리언 값은 `1`, `true`, `yes`, `on`을 참으로 봅니다.

예시 (사내망 서비스):

```ini
bind=0.0.0.0
port=5900
user=me
password_hash=pbkdf2-sha256$...   ; passwd가 만든 값
jpeg_quality_max=85
jpeg_quality_min=40
```

## 7. 명령행 옵션

```text
daramvnc [run] [옵션]        포그라운드 실행 (Enter로 종료)
daramvnc passwd <user>       로그인 사용자와 비밀번호 설정
daramvnc vncpasswd           VNC 비밀번호 설정
daramvnc install [--open-firewall] | uninstall | start | stop
daramvnc gui                 설정 창 (관리자 권한 요청, 3장)
daramvnc version             버전 출력
daramvnc help                사용법 출력
```

`run` 옵션(설정 파일 값보다 우선합니다):

| 옵션 | 설명 |
|---|---|
| `--port N` | 포트 |
| `--bind ADDR` | 수신 주소 |
| `--config FILE` | 설정 파일 경로 |
| `--view-only` | 입력을 무시하는 보기 전용 모드 |
| `--h264` | H.264 켜기 |
| `--jpeg-max Q`, `--jpeg-min Q` | JPEG 품질 상한 / 하한 |

`--port`는 `install`에도 적용됩니다(방화벽 규칙의 포트).

### H.264

영상처럼 계속 바뀌는 큰 영역을 **같은 화면에서 전송량을 크게 줄여** 보낼 수 있지만, 뷰어가 H.264(Open H.264, 인코딩 50)를 지원해야 합니다. 지원 여부를 확인하지 못해 기본은 꺼져 있습니다. 뷰어가 지원하지 않으면 켜도 쓰이지 않고 Tight로 보냅니다. 인코더 오류가 나면 자동으로 Tight로 돌아갑니다.

## 8. 화면 품질과 속도

- 텍스트·UI 영역은 항상 **무손실**입니다. 색이 많은 사진·영상 영역에만 JPEG을 쓰고, 화면이 멈추면 그 영역을 무손실로 다시 보냅니다.
- JPEG 품질은 `jpeg_quality_min`~`jpeg_quality_max` 사이에서 자동으로 움직입니다. 지연이 70 ms를 넘으면 빠르게 내리고, 30 ms 아래가 이어지면 천천히 올립니다.
- 빠른 LAN에서 CPU를 더 아끼려면 상한을 낮추세요(예: `jpeg_quality_max=70`). 느린 회선에서 화면이 거칠어 보이면 하한을 올리되, 그만큼 지연이 늘 수 있습니다.
- 스크롤과 창 이동은 CopyRect로 거의 대역폭을 쓰지 않습니다.

## 9. 기능 동작 안내

| 기능 | 동작 |
|---|---|
| 키보드 | 글자는 레이아웃과 IME에 맞춰 입력되고, Ctrl/Alt 단축키와 비문자 키는 스캔코드로 보냅니다. 한글 같은 유니코드도 입력됩니다 |
| 마우스 | 이동, 버튼, 휠(4방향). 화면 밖 좌표는 화면 안으로 보정됩니다 |
| Ctrl+Alt+Del | 서비스(SYSTEM 에이전트)로 실행할 때만 동작합니다 |
| 연결이 끊길 때 | 눌려 있던 키와 버튼을 서버가 모두 해제합니다 |
| 클립보드 | 텍스트(UTF-8)를 양방향으로 공유합니다. `view_only`면 무시합니다 |
| 해상도 변경 | 뷰어가 요청하면 디스플레이가 지원하는 **정확한 해상도일 때만** 바꾸고, 마지막 클라이언트가 끊기면 원래대로 되돌립니다. 임의 크기와 모니터가 여러 개인 경우는 거절합니다 |
| 여러 클라이언트 | 동시 접속을 지원합니다. 캡처는 하나를 공유하고 클라이언트마다 따로 전송합니다. 접속자가 없으면 캡처를 멈춥니다 |
| 멈춘 클라이언트 | 1초 넘게 응답이 없으면 새 업데이트를 보내지 않고, 30초 동안 전송이 안 되면 연결을 끊습니다. 다른 클라이언트에는 영향이 없습니다 |

## 10. 로그

- 서비스(에이전트) 실행: 실행 폴더의 `daramvnc.log`에 기록합니다. 위치는 `log=`로 바꿉니다.
- 포그라운드 `run`: 콘솔에 출력합니다. `log=`를 지정하면 파일에도 기록합니다.
- 크기 기준으로 회전합니다 (`log_max_mb`, `log_keep`). 파일을 다른 프로그램이 열고 있어 이름을 바꿀 수 없으면 `.1`로 복사한 뒤 원본을 비웁니다.
- 접속, 인증 실패, 품질 변화, 클라이언트별 성능 통계가 기록되므로 문제가 생기면 먼저 로그를 확인하세요.

## 11. 보안 권장 사항

- 원격에서 접속하게 할 때는 반드시 `passwd`를 설정하고 **TLS(VeNCrypt)** 로 접속하세요. 인증 정보가 없으면 서버가 시작을 거부합니다(루프백 바인딩 제외).
- 인터넷에 직접 노출하지 말고 VPN이나 SSH 터널 뒤에 두세요.
- 방화벽은 필요한 주소 대역만 허용하세요. `--open-firewall`은 모든 주소에서 오는 TCP를 허용하는 규칙을 만들므로, 필요하면 `netsh advfirewall`로 범위를 좁히세요.
- `allow_legacy_vnc_auth`는 꼭 필요할 때만 켜세요.
- 화면을 보기만 하면 되는 용도(교육, 모니터링)에는 `view_only=1`을 쓰세요.
- `daramvnc.conf`와 `server.key`는 일반 사용자가 읽거나 바꿀 수 없는 폴더(예: `C:\Program Files\DaramVnc`)에 두세요.

## 12. 문제 해결

| 증상 | 확인 |
|---|---|
| 다른 PC에서 접속이 안 됨 | `bind`가 `127.0.0.1`로 되어 있지 않은지, 방화벽이 포트를 허용하는지(`install --open-firewall`), 서버 로그에 접속 시도가 있는지 확인 |
| `refusing to listen on ... without authentication` | 인증 정보가 없는데 루프백이 아닌 주소(기본 `0.0.0.0` 포함)에 바인딩한 경우입니다. `passwd`를 먼저 실행하세요 |
| `invalid bind address` | `bind` 값이 올바른 IPv4/IPv6 주소인지 확인 |
| 포트가 이미 사용 중 | 다른 VNC 서버가 5900을 쓰고 있습니다. `--port`나 `port=`를 바꾸세요 |
| 인증 실패가 반복되다 접속이 안 됨 | 같은 주소에서 6번 실패하면 5분간 차단됩니다. 잠시 기다리세요 |
| 뷰어가 "서버가 지원하는 보안 방식이 없음"이라고 함 | 뷰어가 VeNCrypt(X509Plain/X509Vnc)를 지원하는지 확인. 인증 정보가 없는 서버는 보안 없음 방식을 루프백에서만 제공합니다 |
| 인증서 경고 | 자체 서명 인증서이므로 정상입니다. 지문을 확인하고 수락하세요 |
| 화면이 거칠거나 흐림 | 회선 지연으로 JPEG 품질이 내려간 상태입니다. 화면이 멈추면 무손실로 다시 보냅니다. `jpeg_quality_min`을 올려 보세요 |
| 입력이 안 됨 | `view_only`가 켜져 있는지 확인 |
| 잠금 화면·UAC 화면이 안 보임 | 포그라운드 `run`이 아니라 **서비스로 실행**했는지 확인하세요. 일반 사용자 프로세스는 보안 데스크톱을 캡처할 수 없습니다 |
| `install failed (Win32 error 5)` | 관리자 권한 프롬프트에서 실행하세요 |
| 서비스는 켜졌는데 화면이 안 나옴 | `daramvnc.log`에서 에이전트 시작 오류를 확인 |
| 설정을 바꿨는데 적용 안 됨 | 서비스는 `stop`/`start`로 다시 시작해야 합니다 |

## 13. 알려진 제약

- 8비트 색상(컬러맵)은 고정 RGB332 팔레트입니다.
- 해상도 변경은 디스플레이가 제공하는 정확한 모드로만 가능합니다.
- 서비스, 보안 데스크톱, 멀티 모니터, 실제 뷰어와의 호환성은 위 "검증 범위"를 참고하세요.
- 영상 판정은 휴리스틱(연속·대형·사진형 변경)이라 일부 콘텐츠는 H.264를 켜도 Tight로 전송됩니다.
